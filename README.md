# casting-out-nines

checks multiplication problems with the [casting out nines](https://en.wikipedia.org/wiki/Casting_out_nines) method

## example
```js
var c = require("casting-out-nines")

c(528, 367, 193776) // true
c(857, 162, 3949) // false
```
